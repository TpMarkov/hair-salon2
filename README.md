## 📖 About This Project

The **Hair Salon Management System** is a complete digital solution designed to replace manual appointment handling with a modern **web & mobile experience**.

### Who is this for?
* **Salon Owners**: Centralized control over bookings, staff, and services.
* **Clients**: Easy and fast online appointment booking.
* **Developers**: A real-world full-stack project with scalable architecture.

### Key Benefits
* **Online Booking**: Clients can book anytime, anywhere.
* **Centralized Management**: One dashboard for all salon operations.
* **Scalable System**: Shared backend for web and mobile platforms.

---

## ✨ Key Features

### 👩‍🦱 Client Features (Web & Mobile)
* Browse services and prices  
* Choose stylist and time slots  
* Book, reschedule, or cancel appointments  
* View appointment history  
* Mobile-optimized experience  

### 📊 Admin Dashboard
* Manage appointments (create / edit / cancel)  
* Manage services (price, duration, availability)  
* Manage employees / stylists  
* View daily, weekly, and monthly schedules  
* Track booking status (pending / confirmed / completed)  
* Responsive admin interface  

### 📱 Android Mobile App
* Native Android support  
* On-the-go appointment booking  
* Shared REST API backend  
* Push-ready architecture (future notifications)

---

## 🛠️ Tech Stack

This project is built using modern, production-ready technologies:

* **Frontend (Web & Admin)**: React / Next.js, Tailwind CSS v4  
* **Mobile**: Android (Java / Kotlin or React Native – configurable)  
* **Backend**: Node.js, Express, MongoDB  
* **Authentication**: JWT (planned / implemented)  
* **Deployment**:  
  * Vercel – Frontend  
  * MongoDB Atlas – Database  
  * Render / Railway – Backend
