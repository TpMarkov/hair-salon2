# Hair Salon Management System

Live Web App: https://hair-salon-frontend-rho.vercel.app/  
Android App: Coming Soon 🚧  
Admin Dashboard: Included

A **full-stack Hair Salon Management System** that allows customers to book appointments online or via a mobile app, while salon owners manage services, staff, and bookings through a powerful admin dashboard.

---

## ✨ Overview

This project is a **complete digital solution for hair salons**, designed to replace manual appointment handling with a modern web & mobile experience.

It consists of:
- **Customer-facing website**
- **Android mobile application**
- **Admin dashboard for salon management**
- **Centralized backend using MongoDB**

The system is scalable, mobile-friendly, and built with modern web technologies.

---

## 🔥 Key Features

### 👩‍🦱 Client Features (Web & Mobile)
- Browse available services and prices
- Select stylist and preferred time slots
- Book, reschedule, or cancel appointments
- View appointment history
- Mobile-optimized experience
- Android app support

### 📊 Admin Dashboard
- Manage appointments (create / edit / cancel)
- Manage services (price, duration, availability)
- Manage employees / stylists
- View daily, weekly, and monthly schedules
- Track booking status (pending / confirmed / completed)
- Responsive admin UI

### 📱 Android Mobile App
- Native Android support
- Book appointments on the go
- Push-ready architecture (future notifications)
- Shared backend with the web platform
